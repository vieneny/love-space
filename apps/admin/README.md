# 共赴山海手记管理后台

Vue 3 + TypeScript + Vite + Element Plus。与小程序共用 Python 服务，通过独立管理身份访问 `/api/v1/admin`。

## 本地开发

在仓库根目录按根 README 安装依赖，然后在此目录运行 `pnpm dev`。默认访问 `http://127.0.0.1:15173`。

复制 `.env.example` 为 `.env.local` 可以设置 `VITE_API_BASE_URL`。该变量是 API 服务 origin，不包含 `/api/v1/admin`。默认值为 `http://127.0.0.1:18100`；前后端分离部署时，后端需将管理站点来源加入 CORS 允许列表。

管理员在登录页填写由部署者配置的账号、密码。账号密码的环境变量见根 README 和后端配置说明。前端没有内置账号、默认密码或小程序开发登录入口，登录令牌仅存于当前标签页的 sessionStorage，退出时清除。

## 页面与数据

- 概览：实际用户、空间、回忆、旅行、媒体、存储、愿望与习惯数量。
- 用户/空间/回忆：只读元数据。回忆表严格按允许字段渲染，不展示标题、正文、坐标、文件地址。
- 题库：新增、编辑、启用/停用；只有服务成功保存后更新显示。现有 API 未提供删除接口。
- 反馈/审计：只读列表。
- 服务状态：读取后端已脱敏配置；当前版本不提供配置写入。

没有样例用户、假统计、模拟 API 或前端兜底数据。无服务时显示连接错误，空数据库时显示空态。列表搜索与分页作用于本次已加载的数据。

## 校验与发布

`pnpm build` 执行 Vue/TypeScript 类型检查并生成 `dist/`。发布静态站点时需将站内路由回退到 `index.html`，并配置可访问的 HTTPS API。生产环境禁止使用开发账号登录方案；由部署环境安全配置管理员身份。

需要结合实际后端验证：正确/错误登录、令牌过期、空列表、题库新增与重载、题目启停、网络错误恢复、手机宽度导航。静态构建不能证明微信登录、实际用户同步或线上服务已部署。
