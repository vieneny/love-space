# 商用与第三方依赖

第一版业务代码在本仓库新建，未直接套用许可证不明的情侣整站模板。本项目原创业务代码按根目录 LICENSE 中的 MIT 许可证发布，允许在遵守其版权和许可保留要求的前提下商用；这不表示项目的全部第三方内容都采用 MIT，也不授予项目名称、品牌或标志的商标权。具体依赖版本由 pnpm-lock.yaml 和 backend/uv.lock 锁定；代码许可不代表地图、微信平台和其他在线服务同时获得商业授权。

前端已安装依赖的许可证元数据在 frontend-licenses.json；可用 `node scripts/generate-notices.mjs` 重新生成 THIRD_PARTY_NOTICES.txt 和小程序附带的静态声明。分发和二次分发应保留相关版权、许可证及 NOTICE。清单含构建工具的间接依赖，不代表所有条目都会进入客户端运行时代码。元数据统计不是完整法律意见，后续新增依赖需要重新检查实际文件。

当前前端清单包括 MIT、Apache-2.0、ISC、BSD、CC0、CC-BY-4.0 等声明；有署名义务的内容不能因为免费就删除来源。生成器会列出安装包未附根许可证文本的依赖，商用分发前应补查对应上游版本的文件，不能把自动清单当作完整授权。

Python依赖另见 backend/THIRD_PARTY_NOTICES.md。当前锁定并在本地安装核对的 psycopg 3.3.6 与 psycopg-binary 3.3.6 均声明 LGPL-3.0-only，不能将整个依赖栈描述为纯 MIT。复制或再分发其 wheel、预装运行环境或包含它们的容器镜像时，应保留上游版权、完整许可证和必要声明，并按实际分发方式满足 LGPL 的源码提供、库替换或重新链接等适用义务。修改库本身时也须遵守该许可。单独发布本仓库源码和锁文件，不等于已经完成二进制分发审查；PostgreSQL、libpq、加密库及 Docker 基础镜像中的系统组件仍有各自许可。

AI品牌素材的生成与后期记录保存在 assets/brand/avatar-ai-v001/。所用兼容API的型号标识不构成对底层模型来源的证明，供应商商业使用、输出再分发和标志使用条款尚未独立核实。干净母图与叠加署名字标的导出需分别核对来源和权利，不能仅凭生成成功承诺对外商用授权。

原生腾讯地图、海外地点搜索与逆地理编码的服务条款、业务授权、额度和费用必须单独确认。不能把开源地图展示代码视为购买了地图数据的使用权，也不应将 Google Places 的结果随意缓存/显示到不受允许的地图上。

个人主体先做体验。类目、备案、隐私指引和后续经营资格以实际平台要求为准；不因代码允许商用就承诺个人主体的全部功能可以审核上线。目前没有支付或付费会员业务。

本文和自动清单用于说明已知许可边界，不是完整法律意见或无遗漏的商用保证。新增依赖、修改素材或分发二进制/镜像前，应按最终交付内容复核。
